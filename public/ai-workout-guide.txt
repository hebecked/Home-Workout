HOME WORKOUT – AI PLAN GUIDE (SCHEMA VERSION 2)

Use this guide when a user asks you to create a workout plan for the Home Workout web app.
The BASE_URL is the origin from which this text file was loaded.

YOUR TASK
1. Ask for or infer the goal, experience level, equipment, duration, limitations, and preferred languages.
2. Create a balanced phased plan that matches BASE_URL/schema/workout-plan-v2.schema.json.
3. Prefer exercise IDs from the supported library below so the app can show a matching illustration.
4. Return either a Markdown link labelled "Workout öffnen" using BASE_URL/?plan=BASE64URL_UTF8_JSON#import, or the complete JSON in a code block for upload. Encode the compact JSON as UTF-8 base64url without padding.
5. State clearly that the import check covers technical compatibility, not medical or health suitability. Tell the user to review the exercises and workload, train within their ability, use stable equipment and enough space, stop for pain or illness, and seek qualified advice for health-related uncertainty. Do not imply that this limits statutory liability rights.

SUPPORTED EXERCISE IDS
These 52 IDs have built-in illustrations and reference instructions. Every exercise entry must still provide a name and instructions for each configured language.
legs: squat, sumo-squat, reverse-lunge, forward-lunge, split-squat, glute-bridge, single-leg-glute-bridge, calf-raise, wall-sit, sumo-squat-hold
push: push-up, scapular-push-up, incline-push-up, knee-push-up, pike-push-up, triceps-dip
pull: pull-up, assisted-pull-up, chin-up, resistance-band-row, resistance-band-pull-apart
core: dead-bug, lying-leg-raise, bird-dog, plank, side-plank, mountain-climber, hollow-hold, superman, superman-dynamic
cardio: jumping-jack, step-jack, high-knees, marching-in-place, shadow-boxing
full-body: burpee, squat-to-reach
warm-up: heel-dig, shoulder-roll, arm-circle, active-recovery, leg-swing
stretch: calf-stretch, hamstring-stretch, quadriceps-stretch, hip-flexor-stretch, shoulder-upper-back-stretch, chest-stretch, child-pose, cat-cow, cobra-stretch, yoga-bridge

If no supported exercise fits, a custom kebab-case exerciseId is allowed. It will not have a built-in illustration.

PLAN RULES
- schemaVersion must be 2. Older schema-v1 plans remain importable, but new plans should use v2.
- A plan has ordered phases. Include a warm-up, one or more training phases, and a cool-down. Active recovery is optional and distinct from passive rest.
- Phase kinds are "warm-up", "training", "active-recovery", and "cool-down". Warm-up comes before training; cool-down comes after training and is last.
- rounds means repetitions of the phase's complete exercise sequence. repetitions means repeated executions of one movement.
- Each phase owns rounds, restBetweenExercises, restBetweenRounds, and restAfterPhase. These values are non-negative seconds; rounds is a positive integer.
- Active-recovery exercises use duration or untimed targets, not repetition targets.
- Exercise type is "repetitions", "duration", or "untimed". Targets are respectively {"min":8,"max":12,"unit":"repetitions"}, {"seconds":30}, or {}.
- IDs are unique, non-empty safe text without markup. languages, name, displayLanguages, translations, and alternativeExerciseIds follow the schema exactly.
- Use only defined fields. Omit translationMetadata; the app creates it only for its machine-translation workflow.
