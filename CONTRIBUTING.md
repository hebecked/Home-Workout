# Contributing

Issues, bug reports, accessibility feedback, and feature requests are welcome.

Until a Contributor License Agreement (CLA) process is in place, this project does not accept external code contributions for integration. Please do not submit a pull request containing code intended to be merged.

External code contributions must not be merged without an appropriate CLA or explicit copyright/relicensing grant.

Maintainers should keep tests and implementation changes in separate review contexts, preserve the 95% coverage gates, run mutation testing for core logic, and verify dependency licenses before accepting any change.
